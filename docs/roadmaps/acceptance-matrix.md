# Production Acceptance Matrix

Audit date: 2026-07-28  
Source audit: `docs/audits/production-gap-audit.md`

Status values intentionally match the audit vocabulary:

- implemented
- partial
- missing
- blocked
- external dependency
- future roadmap

| Area                                | Mevcut durum   | Acceptance criteria                                                                                                   | Evidence required                                                                 | Packages or paths likely changed                                                     | Blocking risk                                                        |
| ----------------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| Release truth and npm package state | partial        | npm package versions, README, publishing docs, tags, and changesets agree.                                            | `npm view` matrix, release tag, package provenance, passing `pnpm release:check`. | `README.md`, `docs/npm-publishing.md`, `.changeset`, package manifests               | Published package mismatch blocks reliable adoption.                 |
| Dev dependency security audit       | partial        | `pnpm audit --audit-level moderate` passes or approved exceptions are documented.                                     | Audit output, lockfile diff, exception record if needed.                          | `package.json`, `pnpm-lock.yaml`, docs                                               | Tooling vulnerabilities remain in docs/examples/CI chain.            |
| Hosted production registry          | missing        | Public immutable registry and promoted `latest` endpoint validate against schema and load through registry client.    | Deployed URL, manifest checksum, CI publish log, registry smoke test.             | `packages/registry`, `packages/cli`, `scripts`, `.github/workflows`, docs            | No production dataset discovery path exists.                         |
| Artifact publishing/CDN             | missing        | Approved artifacts upload to immutable object paths with checksums, size metadata, attribution, and retention policy. | CDN listing, checksums, build report, source lock, rollback test.                 | `scripts`, `.github/workflows`, `packages/registry`, docs                            | GitHub Actions artifacts are not production distribution.            |
| Registry manifest versioning        | partial        | v1 compatibility tests protect older clients; promoted manifests link immutable versions.                             | Schema tests, sample manifests, rollback dry run.                                 | `packages/registry`, `packages/cli`, docs                                            | Future registry schema changes could break clients.                  |
| Dataset checksum verification       | implemented    | Loader and registry install paths reject corrupted or mismatched artifacts.                                           | Existing tests plus publish smoke with modified checksum failure.                 | `packages/registry`, `packages/core`, `packages/cli`                                 | Signed manifest support is still absent.                             |
| Turkey ADM0-ADM2 artifacts          | partial        | CI rebuilds from source locks and publishes approved artifacts to registry/CDN.                                       | Turkey build report, source locks, checksums, registry artifact entry.            | `packages/generators`, `packages/data-tr`, `scripts`, `.github/workflows`, docs      | Built artifacts are not currently hosted or committed.               |
| Turkey ADM3 ingestion               | partial        | Multi-source ADM3 build is deterministic and emits source, quality, coverage, and policy reports.                     | Source manifests, build logs, quality reports, artifact policy report.            | `packages/generators`, `packages/dataset`, `scripts`, `datasets/registry`, docs      | Current Gaziantep pilot does not prove nationwide ingestion.         |
| Turkey nationwide mahalle coverage  | blocked        | All included ADM3 sources have approved licenses and expected coverage; gaps are explicit.                            | Source review register, coverage matrix, source locks, legal approval.            | `packages/data-tr`, `packages/generators`, `datasets/registry`, docs                 | No approved nationwide ADM3 polygon source is available.             |
| Production geometry gates           | partial        | Publish workflow fails blocking topology/coverage/quality reports unless artifact is marked pilot.                    | CI failure fixture, quality report, publish-ready manifest flag.                  | `packages/generators`, `packages/dataset`, `scripts`, workflows                      | ADM3 pilot is not production-ready.                                  |
| MVT budget/performance policy       | partial        | Each published dataset has tile count, tile size, empty tile ratio, and trend reports enforced in CI.                 | MVT policy report, artifact policy output, trend history.                         | `packages/generators`, `scripts`, workflows, docs                                    | Tile regressions can increase CDN cost and render latency.           |
| Stable ID continuity                | partial        | Registry release compares old/new artifacts and records documented ID changes.                                        | Identity diff report, migration manifest, failing test for undocumented churn.    | `packages/dataset`, `packages/generators`, `packages/cli`, `packages/registry`, docs | Saved external references can break silently.                        |
| Dataset diff/migration              | future roadmap | CLI reports additions/removals/parent changes/geometry changes and emits migration metadata.                          | CLI snapshots, fixture diffs, registry-linked migration report.                   | `packages/dataset`, `packages/generators`, `packages/cli`, docs                      | Dataset upgrades are hard to assess.                                 |
| Leaflet adapter                     | implemented    | Package renders fixture and registry-configured datasets and passes shared adapter lifecycle tests.                   | Unit tests, visual smoke, example app, package dry-run, docs.                     | `packages/leaflet`, `packages/adapter-core`, `packages/runtime`, examples            | MVT requires an application-selected Leaflet plugin.                 |
| OpenLayers adapter                  | implemented    | Package renders fixture and registry-configured datasets and passes shared adapter lifecycle tests.                   | Unit tests, visual smoke, example app, package dry-run, docs.                     | `packages/openlayers`, `packages/adapter-core`, `packages/runtime`, examples         | Projection/source handling needs careful parity.                     |
| React Native adapter                | future roadmap | Mobile app loads, verifies, caches, restarts offline, and renders a dataset.                                          | Mobile smoke test, cache verification logs, docs.                                 | new mobile package, `packages/registry`, `packages/runtime`, docs                    | Platform storage and offline invalidation remain undefined.          |
| Offline data loading                | partial        | Offline install/update/verify/remove flows work in Node and mobile storage abstractions.                              | Registry cache tests, mobile storage tests, corruption recovery test.             | `packages/registry`, `packages/runtime`, docs                                        | Stale or corrupt caches can confuse clients.                         |
| Hosted Turkey demo                  | partial        | Public URL renders Turkey data from production registry with visual smoke coverage.                                   | Deployment URL, Playwright screenshot, registry fetch logs.                       | `examples/web-maplibre-turkey`, workflows, docs                                      | Current example depends on local environment configuration.          |
| Game package                        | future roadmap | Game package consumes public APIs and does not force core/runtime breaking changes.                                   | Package tests, example game, API review.                                          | new `packages/game`, examples, docs                                                  | Premature game APIs could destabilize core contracts.                |
| Release rollback                    | partial        | Previous registry version can be promoted quickly without mutating immutable artifacts.                               | Rollback drill log, incident checklist, registry pointer diff.                    | `packages/registry`, `scripts`, workflows, docs                                      | Bad datasets may remain discoverable without rollback.               |
| Provider registry completeness      | partial        | Generated provider registry includes every built-in production source adapter or an explicit exclusion.               | `datasets/registry/providers.json`, generator test, docs.                         | `scripts/generate-dataset-registry.mjs`, `datasets/registry/providers.json`, docs    | Turkey builds rely on an adapter not reflected in provider metadata. |
| CI duration and bottlenecks         | partial        | CI reports per-stage durations and fails only on defined performance budgets.                                         | GitHub Actions timing, benchmark trend, artifact size trend.                      | workflows, `scripts`, docs                                                           | Manual large dataset build performance can drift unseen.             |
