## Manual Publish Steps

1. Merge this draft PR after review.
2. Run the Turkey dataset build workflow manually from `main`, keep `allow_partial=false`
   for ADM0-ADM2 release evidence unless intentionally validating scoped ADM3, and review
   uploaded artifacts.
3. Let Changesets open or update the version PR from `main`.
4. Review `CHANGELOG.md`, generated versions, tarball dry-run output, and npm Trusted
   Publishing settings.
5. Merge the Changesets version PR.
6. Dispatch the `Release` workflow from `main` with `publish=true`, or let the guarded
   `main` workflow publish when no Changesets remain.
7. Verify npm package pages, provenance, package exports, and registry smoke tests.
8. Create a Git tag or GitHub Release only after npm and registry verification succeeds.
